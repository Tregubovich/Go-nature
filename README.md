# Go Nature — домашние задания

Набор домашних заданий по Go, посвящённых многопоточности, алгоритмам, криптографии, работе с памятью и низкоуровневым программированием.
## Работы

### [Digest](./gonature1-digest-Tregubovich)

Функции для работы с числами и вычисления различных числовых характеристик.

### [LFU Cache](./gonature1-lfucache-Tregubovich)

Реализация **LFU (Least Frequently Used) Cache** — кэша, который при переполнении удаляет элементы с наименьшей частотой использования.

### [ASM](./gonature1-asm-Tregubovich)

Набор функций, реализованных на **Go assembler**. Работа посвящена взаимодействию Go-кода с низкоуровневым ассемблерным кодом.

### [Concrypto](./gonature1-concrypto-Tregubovich)

Многопоточное шифрование данных банковских карт с использованием конкурентного выполнения.

### [Confibgen](./gonature1-confibgen-Tregubovich)

Потокобезопасный генератор **чисел Фибоначчи**, рассчитанный на одновременное использование из нескольких горутин.

### [Factorization](./gonature1-factorization-Tregubovich)

Многопоточная **факторизация чисел** с распределением вычислений между несколькими горутинами.
